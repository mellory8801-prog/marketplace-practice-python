ИНФОРМАЦИОННАЯ СИСТЕМА ДЛЯ МАРКЕТПЛЕЙСА
Учебное программное ядро к отчету по производственной практике

Требования: Python 3.11 или новее. Сторонние библиотеки не требуются.

1. Распакуйте архив в отдельную папку.
2. Откройте терминал в этой папке.
3. Выполните: python marketplace.py
4. Для проверки выполните: python -m unittest -v test_marketplace.py

Демонстрация создает marketplace.db и заказ на 6770 рублей.
Повторный запуск возвращает ранее созданный заказ без повторного списания.
Тесты работают с независимыми базами в памяти и не меняют marketplace.db.

Состав:
marketplace.py — SQL-структура, тестовые данные и операции;
test_marketplace.py — 12 автоматизированных проверок;
test-results.txt — вывод проверочного запуска;
README.txt — инструкция.

Реализованы оформление и отмена нового заказа, проверка роли покупателя,
остатков, исторической цены, повторного запроса и журналирование.
Веб-интерфейс, вход пользователей, платежи и доставка не реализованы.
Изображения интерфейса в отчете являются проектными макетами.

При добавлении веб-оболочки пользователь должен определяться по проверенной
сессии. Нельзя передавать непроверенный buyer_id из клиентской формы.
